Como criar variáveis personalizadas

Consulte exemplos prontos e adapte os nomes das variáveis à sua regra.

Retornar valores conforme uma condição

Use valor_se_verdadeiro if condição else valor_se_falso.

"Feminino" if paciente.sexo == "F" else "Masculino" if paciente.sexo == "M" else "Outro"

Separar data e hora

As funções aceitam datas do sistema e textos nos formatos brasileiros ou ISO.

data(atendimento.data_hora)

Resultado: 28/06/2026

hora(atendimento.data_hora)

Resultado: 14:45:00

Juntar duas ou mais variáveis

Inclua textos fixos entre aspas para separar os valores.

juntar(paciente.nome, " · Prontuário: ", paciente.codigo)

Alterar textos

maiusculo(paciente.nome)
minusculo(paciente.nome)
titulo(paciente.nome)
substituir(atendimento.tipo, "_", " ")

Realizar cálculos

São permitidos + - * / %, comparações e arredondamento.

arredondar(paciente.peso / ((paciente.altura / 100) * (paciente.altura / 100)), 2)

Calcular idade do paciente

Use a data de nascimento do paciente e a data atual do sistema.

idade(paciente.nascimento)

Se precisar calcular em uma data específica, use a data do atendimento como referência.

idade(paciente.nascimento, atendimento.data_hora)
